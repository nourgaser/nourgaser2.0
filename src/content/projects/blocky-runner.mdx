A 3D endless runner game built in Unity, with a focus on custom editor tooling.
The gameplay loop is simple: avoid obstacles and collect coins as the level
scrolls forward. What made this project interesting was building the level
editor tools inside the Unity Editor itself — tools for platform placement,
slicing, combining, and spread generation.
